Several vaults on one phone

Not every private file belongs in the same bucket. Vireault supports more than one vault so you can separate work, family or personal media.

How it works

  • Each vault has its own unlock secret
  • Items stay inside the vault you import them into
  • Free plan: 1 vault and 50 items
  • Pro raises vault and item limits

What is not included yet

Pro includes a hidden vault list and decoy vaults: the lock screen does not show vault names, and the secret you enter selects the matching vault. Hidden mode is not forensic-proof — directory counts, sizes and markers can still reveal that vaults exist. Folders inside a vault are supported.
