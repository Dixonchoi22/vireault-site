How to lock a folder on Android

Search results promise a universal “lock folder” switch. Reality is messier: some phones include Secure Folder or Locked Folder style tools, while stock Android file managers often do not encrypt a directory for you.

Option A — Manufacturer secure spaces

Samsung Secure Folder, Google Photos Locked Folder, and similar OEM features can isolate media behind device authentication. They are excellent when you already live in that ecosystem. They may not travel cleanly if you switch brands.

Option B — App-level vault instead of a filesystem folder

When you need a portable approach, import files into an encrypted vault. That is not identical to locking an existing folder path, but it solves the same user job: keep selected files out of casual reach. Vireault supports photos, video, audio and PDF, with folders inside the vault.

Option C — Encrypt before you share or archive

If your goal is long-term storage, export an encrypted backup and keep it somewhere you control. A locked UI without a backup plan fails the day the phone is wiped.

Practical steps with Vireault

  1. Install from Google Play and create a vault with PIN, pattern or passphrase.
  2. Import the files you would have placed in a locked folder.
  3. Confirm they open inside the vault.
  4. Delete originals only after you are satisfied.
  5. Create an encrypted backup before changing devices.
